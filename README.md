# 📸 React Photography Portfolio

A responsive and visually appealing photography portfolio built with React, TypeScript, DaisyUI, and Tailwind CSS. Designed for showcasing photos with a modern, mobile-first UI and smooth user experience.

---

## 🚀 Features

- **Responsive Design:** Mobile-friendly layout using Tailwind CSS and DaisyUI components  
- **TypeScript:** Strongly typed for better developer experience and maintainability  
- **Photo Gallery:** Dynamic photo display with navigation and lightbox support  
- **Custom Styling:** TailwindCSS utility classes combined with DaisyUI components for clean UI  
- **Easy Deployment:** Ready to deploy on platforms like Vercel or Netlify  

---

## 🛠 Tech Stack

- React  
- TypeScript  
- Tailwind CSS  
- DaisyUI  
- React Photo Album (or similar gallery library)  
- Lightbox for image viewing  

---

## 📦 Installation

1. Clone the repo:  
   ```bash
   git clone https://github.com/DLC-17/react-photography-portfolio.git
   cd react-photography-portfolio
2. Install the dependencies:
   ```bash
   npm install
    or
   yarn install

3. Start the development server:
   ```bash
   npm start
   or
   yarn start
Open http://localhost:3000 in your browser to view the portfolio.
